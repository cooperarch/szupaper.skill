# 交付前自检

编译成功后，把 `main.pdf` 逐页渲染成图片目检。至少核对：

- 封面在第 1 页，校徽、题目、姓名、专业、学院、学号、指导教师、职称、日期全部正确且同一页。
- 诚信声明题目与正文里的论文题目完全一致；签名与日期留空（不要代签）。
- 目录页码与实际落页一致，摘要、致谢、参考文献都出现在目录。
- 页眉是“深圳大学本科毕业论文 + 短标题”，没有上游例子的旧标题。
- 正文页脚为“第 X 页 共 Y 页”，Y 与 PDF 实际页数一致；若英文摘要不在最后一页，Y 会偏小。
- 参考文献按 `plain` 样式编号，正文 `\citep/\citet` 全部解析，无 `[?]`。
- 中文摘要、英文摘要、关键词内容已替换，无 `【待填写：…】`。
- 图表均被正文提及，编号连续，图片无越界或压住文字；过宽的 `includegraphics` 会产生 Overfull hbox。

快速文本检查：

```bash
rg -n "待填写|徐留成|2012080173|潘微科|融合内容信息的单类协同" <工程目录>
python scripts/build_thesis.py <工程目录> --strict
```

`rg` 有命中就说明仍有上游样例内容；`--strict` 会把未填占位符报成失败。
